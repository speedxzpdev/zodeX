# ZodeX

A Simple downloader music and video.

![cat](/src/assets/icons/cat.jpg)

## Install

- Go to the repository's **Release** page
- Go to **assets**

## Development Install

### Build

```bash
npm run build:all
```

```bash
npm run build:tsc
```

```bash
npm run build:electron
```

### Development test

```bash
npm run dev
```

## Stack

- Electron
- Node 25
- Typescript
- ffmpeg
- yt-dlp

## About

The project uses IPC protocol communication between processes. However it's my first time using Electron and IPC. if you like the project, consider giving it a star(:
